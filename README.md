# ATS Resume Analyzer 🚀

An AI-powered ATS (Applicant Tracking System) Resume Analyzer built using Flutter Web and Groq AI.

This project helps users analyze resumes, calculate ATS compatibility, identify missing keywords, and get smart AI-powered improvement suggestions.

---

## ✨ Features

* 📄 Upload Resume PDF
* 🤖 AI-Powered Resume Analysis
* 📊 ATS Score Generation
* 🔑 Missing Keywords Detection
* ✅ Strengths & Weaknesses Analysis
* 💡 Resume Improvement Suggestions
* 🌐 Flutter Web Support
* 🎨 Modern Clean UI

---

## 🛠 Tech Stack

* Flutter
* Dart
* Groq AI API
* HTTP Package
* File Picker
* Syncfusion PDF

## 🚀 Getting Started

### 1️⃣ Clone Repository

```bash
git clone https://github.com/Ronak-Prajapat/ats-resume-analyzer.git
```

---

### 2️⃣ Open Project

```bash
cd ats-resume-analyzer
```

---

### 3️⃣ Install Dependencies

```bash
flutter pub get
```

---

### 4️⃣ Run Project

```bash
flutter run -d chrome
```

---

## 🔑 API Configuration

Get your Groq API key from:

https://console.groq.com

Then add your API key inside:

```dart
lib/services/gemini_service.dart
```
